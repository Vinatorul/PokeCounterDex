# Pokémon sprite sources

These are the existing default front, non-shiny PNG sprites supplied by [PokeAPI/sprites](https://github.com/PokeAPI/sprites), downloaded without alteration. The local file `N.png` corresponds to National Pokédex species ID `N`, for IDs 1–1025.

Source revision: [`0b133a62e914976d3d7ea33aaa1ac676ca248c30`](https://github.com/PokeAPI/sprites/tree/0b133a62e914976d3d7ea33aaa1ac676ca248c30), committed September 20, 2026.

Source path: `sprites/pokemon/{id}.png`. `manifest.json` records each exact source URL, SHA-256, byte count, dimensions, transparency support, and any download failures.

The collection contains official game sprites and existing community sprites in the Black & White pixel-art style. The upstream README credits the Smogon community for later-generation sprites and KingOfThe-X-Roads for Generation IX default front sprites. See `README.upstream.md` for the full original credits and source links. No images in this local collection were generated or modified for this project.
